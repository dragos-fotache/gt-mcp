## Delivered interface and commands

`dist/lifecycle/index.js/.d.ts` exports `signOutProfile({configPath},signal)` and
`retireProfileOperation({configPath},operationId,signal)`. Both capture trusted
inputs, use strict protected T07 metadata, refuse pending transitions, acquire
the actual T04 owner, recheck binding/metadata and await owned release. No ambient
configuration, credential flags or policy override.

```text
node dist/cli/main.js sign-out --config <absolute normalized config path>
node dist/cli/main.js retire-operation --config <absolute normalized config path> --operation-id <operation UUID> --confirm
node dist/cli/main.js recover --config <absolute normalized config path>
```

Stop the stdio owner before CLI lifecycle actions; no force takeover. Sign-out
reuses T06 clearing/generation fences and preserves exact operation bytes/digest
keys even if logout fails. The additive strict credential-free LoginReceipt v1
kind `sign-out` records same-account source/next generation before clearing.
Publish descriptor/remove receipt after acknowledgement. Once intent is prepared,
signals wait for clearing/publication/release; cancellation never claims rollback.

Recover verifies either an unchanged source (sign-out did not commit) or an
already-committed credential-empty lifecycle-v3 target, without login/backend
traffic. Targets retaining grant/pending/superseded material fail closed. Source
recovery is not completed sign-out; repeat the trusted action explicitly if wanted.
Same-account explicit login reopens original identity; another account is refused.

Retirement prints the remote-draft/saved-data/no-rollback warning before effects;
failed output prevents action. It shares the actual owner with T06/T09 and calls
accepted retireOperation. Creation-disabled config works; live auth still applies.
Permanent tombstone erases unresolved bodies and reserves the ID even for changed
intent. Missing IDs/definitive receipts cannot be replaced. No backend DELETE or
MCP lifecycle tool. Stdout stays empty; stderr excludes private inputs/raw errors.
Operator guidance: [login.md](../login.md).
